EA Tools 1.0.0 - Arc Wall Shape to PROKON (AutoCAD 2021)
========================================================
ปุ่ม Arc Wall Shape to PROKON อยู่ในหมวด PROKON ของแท็บ EA Tools
คำสั่งใหม่: WALLARC2PROKON
ปุ่มและคำสั่งเดิมทั้งหมดยังอยู่เหมือนเดิม

วิธีใช้
1. วาดแบบด้วยหน่วยมิลลิเมตร เลือกขอบคอนกรีตจริง ไม่ใช่แนว Cover หรือ Centerline
2. JOIN ขอบให้เป็น Lightweight 2D Polyline เส้นเดียว แล้วตั้ง Closed = Yes
3. กด Arc Wall Shape to PROKON หรือพิมพ์ WALLARC2PROKON
4. เลือก Polyline ที่ปิดแล้ว
5. กรอกค่าความคลาดจากโค้งสูงสุด เป็น mm เช่น 0.25
   ต้องกรอกทุกครั้ง ไม่มีค่าเริ่มต้นและไม่จำค่าครั้งก่อน
   ค่ายิ่งเล็ก ยิ่งได้จุดมาก; 0.25 คือระยะคลาด ไม่ใช่ระยะห่างระหว่างจุด
6. เลือก Concrete สำหรับเนื้อคอนกรีต (+) หรือ Opening สำหรับช่องเปิด (-)
7. ไปที่ PROKON General Column > COLUMN SECTION
   คลิก Code ในแถวว่าง แล้วกด Ctrl+V
   ถ้ามีข้อมูลหน้าตัดเก่าอยู่ ต้องจัดการแถวเดิมก่อนเพื่อไม่ให้มีรูปเก่าซ้อน

รูปแบบ Clipboard
+  X  Y  (หรือ - สำหรับช่องเปิด)
L  X  Y
L  X  Y
คั่นช่องด้วย TAB ใช้พิกัด WCS จริง ไม่หักจุดกำเนิด ไม่มี Header
PROKON ปิดรูปจากจุดสุดท้ายกลับไปจุดแรก
สำหรับหน้าตัดที่มีช่องเปิด ให้คัดลอกขอบนอกก่อน แล้วคัดลอก Opening ต่อด้านล่าง
ถ้าใช้ร่วมกับ Points to PROKON ให้กด Enter ที่คำถามจุดอ้างอิงของเหล็ก
เพื่อให้พิกัดตรงกับขอบ Arc Wall ที่ส่งออกตาม WCS จริง

ขอบเขต
- รองรับ Polyline ที่มีทั้งเส้นตรงและ Circular Arc รวมมุมเกิน 180 องศา
- แบ่ง Arc ด้วยเงื่อนไขระยะเบี่ยงเบนสูงสุด แล้วส่งออก L แบบ Absolute
- ใช้หน่วย mm โดยไม่มีการแปลงหน่วยอัตโนมัติ
- รองรับ UCS ที่หมุนอยู่ แต่ผลส่งออกยังคงเป็น WCS XY
- ไม่แก้เส้นต้นฉบับ ไม่สร้างเหล็กหรือแรงกระทำ
- ไม่รับเส้นเปิด, ARC แยกชิ้น, SPLINE, 3D Polyline, รูปเอียงออกจาก WCS XY,
  Polyline ที่มี width/thickness หรือผลแบ่งเส้นตัด/สัมผัสตัวเอง
- จำกัด 5,000 แถวต่อครั้ง และค่าความคลาดต้องมากกว่า 0.000002 mm
- พิกัดออกละเอียด 6 ตำแหน่งทศนิยม พร้อมเผื่อค่าปัดเศษในเงื่อนไขแบ่งโค้ง
