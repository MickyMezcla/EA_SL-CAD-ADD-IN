# EA Tools for AutoCAD 2021

EA Tools adds a single AutoCAD ribbon tab for PROKON transfer and reinforcement detailing.

- **PROKON** — Points to PROKON, Cover to Bar Points (including Corewall), Wall Shape to PROKON, and Arc Wall Shape to PROKON.
- **Column** — Draw Column, Draw C-Link, and Points to Rebar.

## Install v1.0.5

Download [EA_Tools_1.0.5_AutoCAD2021.zip](EA_Tools_1.0.5_AutoCAD2021.zip), close AutoCAD, and extract the ZIP. Put the complete `EA.Tools.bundle` folder in `%APPDATA%\Autodesk\ApplicationPlugins\`, replacing an earlier EA Tools bundle if present. Move the separate PROKON Tools and Column Tools bundles out of ApplicationPlugins if they are still installed. Open AutoCAD 2021 to load the EA Tools tab.

See the [Thai user guide](EA.Tools.bundle/README_TH.txt) and the [Arc Wall guide](EA.Tools.bundle/README_ARC_WALL_TH.txt).
